# Traffic Sign Recognition using CNN

An end-to-end AI application that classifies German traffic signs using a Convolutional Neural Network trained on the **GTSRB** dataset. The system includes a FastAPI backend, a trained Keras CNN model, and a modern React + TypeScript + Tailwind CSS frontend.

---

## Features

- 🧠 **43-class CNN classifier** trained on the German Traffic Sign Recognition Benchmark
- 📤 **Image upload** — drag-and-drop or browse (PNG, JPG, WEBP)
- 📊 **Confidence score** with animated progress bar
- 🏆 **Top-3 predictions** with per-class confidence
- ⚡ **FastAPI REST backend** with `/predict` and `/health` endpoints
- ⚛️ **React + TypeScript frontend** with Tailwind CSS
- 🖥️ **GPU-accelerated training** (CUDA via TensorFlow)
- 📈 **Training plots** — accuracy, loss, confusion matrix

## Dataset

**GTSRB — German Traffic Sign Recognition Benchmark**

- ~51,000 images, 43 classes
- Real-world traffic sign photos captured in Germany
- Variable lighting, weather, and perspective conditions
- Source: [https://benchmark.ini.rub.de/gtsrb_news.html](https://benchmark.ini.rub.de/gtsrb_news.html)

The dataset is downloaded automatically via `kagglehub` when you run the training script.

---

## Model Architecture

```
Input: 32 × 32 × 3

Conv2D(32) → BatchNorm → Conv2D(32) → MaxPool(2×2) → Dropout(0.25)
Conv2D(64) → BatchNorm → Conv2D(64) → MaxPool(2×2) → Dropout(0.25)
Conv2D(128) → BatchNorm → Conv2D(128) → MaxPool(2×2) → Dropout(0.25)

Flatten
Dense(512, ReLU) → BatchNorm → Dropout(0.5)
Dense(43, Softmax)
```

- **Optimizer**: Adam (lr=1e-3, with ReduceLROnPlateau)
- **Loss**: Sparse Categorical Cross-Entropy
- **Augmentation**: Rotation ±10°, width/height shift ±10%, zoom ±10%, brightness ±20%
- **Callbacks**: EarlyStopping (patience=7), ModelCheckpoint, ReduceLROnPlateau

## Installation

### Prerequisites

- Python 3.11+
- Node.js 18+
- GPU recommended (CUDA-capable for fast training)
- Kaggle account (for dataset download via kagglehub)

### 1. Clone / open the project

```bash
cd traffic-sign-recognition
```

### 2. Backend setup

```bash
cd backend
pip install -r requirements.txt
```

### 3. Train the model

```bash
# From project root
python ml/train.py
```

This will:
1. Download GTSRB dataset via `kagglehub`
2. Train the CNN for up to 30 epochs
3. Save the best model to `models/traffic_sign_cnn.keras`
4. Generate `results/training_accuracy.png` and `results/training_loss.png`

### 4. Evaluate the model (optional)

```bash
python ml/evaluate.py
```

Generates `results/confusion_matrix.png` and `results/classification_report.txt`.

### 5. Start the backend

```bash
# From project root
python -m uvicorn backend.main:app --reload --port 8000
```

### 6. Start the frontend

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## API Reference

### Health Check

```
GET /health
```

Response:
```json
{
  "status": "ok",
  "model_loaded": true
}
```

### Predict

```
POST /predict
Content-Type: multipart/form-data
```

Body: `file=<image file>`

Response:
```json
{
  "prediction": {
    "class_id": 14,
    "name": "Stop",
    "confidence": 97.42
  },
  "top_predictions": [
    { "class_id": 14, "name": "Stop",     "confidence": 97.42 },
    { "class_id": 17, "name": "No Entry", "confidence": 1.32  },
    { "class_id": 13, "name": "Yield",    "confidence": 0.61  }
  ]
}
```
